# OdinTracker Songs Page (Community Contributors)

Archived from the official OdinTracker site. These were the demo songs distributed
to showcase the tracker and let users learn instrument design.

## Key Quote
"To make the most of them, examine the instruments to see how the wave and arpeggio
table are used."
"Because the song format keeps changing, first try the songs that are created with
the version of the tracker you are using."

## Contributor Notes
- **Cadaver (Finland):** C64 scene coder/musician, author of DASM (the assembler used to build OdinTracker).
- **SounDemoN (Finland):** Member of Church 64, Dekadence, Onslaught — the primary musician contributor.
- **Smalltown Boy (Poland):** Multiple contributions across both format versions.
- **Jericho Swathe:** Unidentified contributor (no country listed).

## Relevance for USF Research
These songs represent real OdinTracker 1.0x and 1.1x+ format compositions. The
archived .PRG files in `songs/10x/` and `songs/11x/` on Wayback are the unpacked
C64 data (memory images), which can be used as corpus for format analysis.

Additional songs appeared in the Wayback CDX (not in the 2001-01-29 snapshot):
