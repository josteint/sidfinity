## Notes for migration planning

- All 159 SIDs use the vplayer relocatable player (packed song format).
- Songs made with v1.0x lack filter table data (instruments have 13 bytes of effect data, not 16).
  The HVSC SIDs might be either 1.0x or 1.1x format — need to inspect PSID headers + load addresses
  to determine which vplayer version is embedded.
- Multi-song SIDs are possible (SounDemoN's Nine_Inch_Ninjas_part_N might be multi-subtune).
- No digi/sample support exists in OdinTracker — it's a pure tracker.
- CIA/multispeed: no evidence of anything other than standard 50 Hz (vplayer uses VBI).
