# OdinTracker — HVMEC (Scene Archive) Coverage

HVMEC (hvmec.altervista.org) is a C64 music-tracker archive that documents
every known music editor for C64. OdinTracker has three entries.

## v1.00 entry (https://hvmec.altervista.org/blog/?p=2338)

Key features noted:
- Three-voice music composition (3-channel, 3-voice SID chip)
- Pattern-based sequencing with orderlist editor
- Instrument editor with wave, arp, and filter tables
- Per-voice mute controls
- Block operations: cut, copy, paste, transpose
- Keyjazz for real-time note input
- Track transposition and mixing
- Undo for block operations
- Linear interpolation for data fill within blocks
- Source code provided (tracker.s)
- Executable binary as .d64 disk image

## v1.10 entry (http://hvmec.altervista.org/blog/?p=2393)

- Same editor sections: pattern, instrument, orderlist
- "Pack and Save" functionality added (packer)
- Sample songs included: bossa.prg, darkness.prg, firelord.prg
- Source code available for all versions
- HISTORY document and README bundled

## v1.13 entry (https://hvmec.altervista.org/blog/?p=2430)

- Final release (17 Apr 2001) — marked in HVMEC catalogue
- Same feature set as v1.10 plus:
  - Effect management with grab/drop
  - Disk operations: song import/export
  - Voice muting up to 4 voices (3 voices + all)
  - Undo for block edits
  - Two downloads: binary + source
