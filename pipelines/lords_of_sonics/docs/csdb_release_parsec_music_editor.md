# The Parsec Music Editor V5.1 — CSDb Release Pages

## Summary

The Parsec Music Editor V5.1 is the main distributed form of the LordsOfSonics/MS player/editor tool. It was created by Markus Schneider (Lords of Sonics / X-Ample Architectures) in 1989 and distributed by various scene groups from 1989–1991.

## Key Technical Detail

From user comment on the 2023 LOS Music Editor release (ID 230753):

> "Basically it's another editor using **the same player code as The Parsec Music Editor V5.1**" — iAN CooG

This confirms that the player code in Parsec V5.1 is identical to the Lords of Sonics Music Editor's player, establishing a direct lineage.

---

## Version "V5.1" Context

The "V5.1" designation raises the question of what versions V1–V5.0 looked like. There is no CSDb evidence of earlier named versions. The high version number suggests either:
1. The editor underwent many internal revisions before public release, or
2. The version numbering is non-linear (common in scene tools)

The 2023 "LOS Player Leo Tune Editor v1.0" (ID 230753) uses "LOS Player" branding and appears to be a modern reconstruction/repackaging rather than a historical version 1.

---

## Relation to Compotech

Compotech (1992, X-Ample) and Compotech V2.1 (1995, X-Ample) are the successors to Parsec Music Editor V5.1. All share Markus Schneider as coder. The engine is believed to be the same underlying player routine, with Compotech adding the workflow described in user comments:
- Compotech saves **packed song data** (not a standalone executable)
- A separate **'.PLAYER-ROUTINE'** is merged to create a playable file
- V2.1 adds turboass format export
