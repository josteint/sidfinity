### Address Pattern

Blidon SIDs consistently follow:
- Init address = Load address + 3
- Play address = Load address

This is the same pattern as Markus Schneider's LOS-era SIDs, confirming shared engine code. The consistent "+3" offset for init suggests the first 3 bytes of the player are a `JMP` instruction (3-byte 6502 opcode) to the actual initialization code.
