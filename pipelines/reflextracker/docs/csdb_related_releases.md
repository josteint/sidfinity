## TinySID (kb's SID emulator)

| CSDb ID | Title | Year |

| 144397 | TinySID V0.965 | 2006 |
| 144394 | TinySID V0.966 | 2007 |
| 155237 | TinySID V0.97 | 2008 |

TinySID is a cross-platform C64 SID emulator written by kb. The `fakesid` Android app (https://2bt.github.io/fakesid/) credits TinySID as its foundation. TinySID does not have special Reflextracker support; it emulates the SID chip generically.

## Liquid Sound Designer (LSD) — CSDb #118872

Key technical details:
- **Released:** July 20, 1997 at Wired 1997 event
- **Code:** kb + Quiss
- **Idea/Test:** PVCF
- **Type:** Demo version only (disk routines missing; need Action Cartridge)
- **Capability:** 3-channel SID chip duration editor
- **Relationship:** LSD is a C64-native editor, Reflextracker is a PC-based tracker
- **Limitation:** Action Cartridge bug prevented proper saving in demo version
- Downloads: `wired97.d64` (532 downloads), `LSD.d64` (166 downloads)
