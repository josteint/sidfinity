# CSDb Comments Compilation — Reflextracker and Related Releases

## CSDb Release #43348 — Reflex-Tracker V1.1

URL: https://csdb.dk/release/?id=43348

### Comment by CJ Warlock (2017-12-02):

> "I've set the year of release to 1995 (as I'm pretty sure of what I remember) and I've added
> two SID's that were on the ReflexTracker disk as demo songs: Gubber and Trance 202."

Note: CJ Warlock (real name Piotr Grabowski) is the most prolific Reflextracker composer in
HVSC (25 SIDs), and he added these SIDs to the CSDb entry from personal recollection —
indicating he had the original distribution disk. He also notes "Gubber" may have been
intended as "Gabber" (the electronic music genre), but the PVCF spelling is what stuck.

## Brainbeat III (CSDb #6830, 1995)

URL: https://csdb.dk/release/?id=6830

A user comment: "I first got it right away in 1995 or maybe a bit later in 1996, together with
ReflexTracker on another disk."

This confirms Brainbeat III was **distributed together with the Reflextracker tool disk** —
the primary mechanism by which the tool reached the broader (especially Polish) C64 scene.

## External Download Mirror

From pouet.net comment (tomaes, 2012):
- c64.rulez.org: `http://c64.rulez.org/pub/c64/Demos/t/The_Obsessed_Maniacs/Tools/Reflextracker_V1.1.zip`

The ZIP file downloaded from CSDb (13,369 bytes) is actually a **T64 tape image** (file type
"C64S tape file"), not a ZIP archive. Contents: 1 entry named "THE3-0WIZARD DD.T64". This
is the binary container for the Reflextracker application as distributed on C64 tape/disk.
