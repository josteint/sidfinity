  - Linking: Day
- **Downloads:** 920 (recorded by CSDb)
- **External source:** Pokefinder.org repository

## Notes

This is a cracked version of the Ariston Music Editor — the GUI editor that
Philip Brabbin programmed for the Ariston driver. The crack allowed scene
members to use and study the editor.

- **External source:** Pokefinder.org

## Notes on the two CSDb entries

Two separate crack releases of the Ariston Music Editor exist on CSDb (#29914
and #119920), both by Criminals in Computers. The #29914 version additionally
credits Illusion. Both are D64 disk images. The difference between the two
cracks is not documented in the available CSDb metadata.

The description of entry #119920 notes: "This is an **improved version of the
player/editor by Ian Crabtree**," confirming Ian Crabtree as the original
player author and Brabbin as the editor author.
