# Atari Forum — Wally Beben's Music Driver (Ariston ST Port)

## Thread Summary
- Title: "Wally 'Hagar' Beben's music driver"
- Original reverse engineering by Mug UK (administrator), 2004
- Thread posts dated August 23–24, 2011
- Focus: reverse engineering the R-Type (Atari ST) music replayer

## Key Facts
- Mug UK RE'd the R-Type replayer for Atari ST in 2004, revised version posted 2011
- Maartau created a revised version of the original code rip
- Xerud previously created music rips
- **Critical fact:** Wally Beben reportedly **lost his original Ariston source code** due to hard drive failures
- Community initiative aimed to reconstruct via reverse engineering

## Technical Detail Available
- R-Type replayer source code attached (reverse engineered, not original)
- Memory addresses for use with Easyrider debugger provided by Xerud
- No note-data format specification in the text extract
- "Not being a musician, I wouldn't have a clue about how his note data is stored" (Mug UK)

## Implication
- Original Ariston source is LOST (Beben's own copy gone)
- The Atari ST port is what this thread refers to — but the underlying note format should be the same as C64 Ariston
- A reverse-engineered Atari ST replayer exists in community hands (Mug UK + Maartau)
- This is a potential alternative source for format documentation if retrieved

## Atari ST Port Details (from VGMPF)
- Ported in 1988 by Wally Beben
- With help of "a very good friend, game programmer Chris from Bury St Edmunds, Suffolk"
