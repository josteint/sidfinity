# Ariston — VGMPF Wiki Page Summary

## Overview
Ariston was a "popular Commodore 64 music driver in the United Kingdom of the late 1980s," released in 1987.

## Key Personnel
- **Creator:** Ian Crabtree (1987)
- **Co-developer:** Wally Beben (updates, port)
- **Editor Programmer:** Philip Brabbin
- **Assistant:** Charles Deenen (programmer — likely Maniacs of Noise connection)

## Technical Specifications
- **Language:** 6502 Assembly
- **Platforms:** C64 (original), Atari ST, Amiga (1988 ports by Beben)
- **Tuning:** "All tuned at 424 or 434 Hz"
  - Leitch specifically: "424 Hz (briefly 434 Hz in 1988)"
- **Composition method:** "Almost all composers arranged in a 6502 assembler" — NOT using the editor GUI
- **Multiple versions:** "Several modified versions of the driver exist"
- **Maniacs of Noise drums:** In late 1987, MoN received source code from Beben, added better drums, returned it
- **Atari ST/Amiga port:** 1988, by Beben, with help of "Chris from Bury St Edmunds, Suffolk"

"These tunes were meant to be included in the game 'Summer Olympiad', (C) 1988 Tynesoft, where both Crabtree and Wally Beben are credited for the music, but only Beben's tunes were used. See /MUSICIANS/B/Beben_Wally/Summer_Olympiad.sid"
