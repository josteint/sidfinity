 Control 1 - Edit track #1
  '  '   2 - Edit track #2
  '  '   3 - Edit track #3
  '  '   4 - Edit sounds

 In trackedit : Control 5 - Block edit
                (Prezz again=exit B.E)
             a  b  c
 Screen   1 xx xx xx  a=trackposition
 displays 2 xx xx xx  b=blockposition
          3 xx xx xx  c=blockduration

 In Blockedit press RETURN to put work-
 pad into block. Don't forget to press
 return if ya wanna exit block edit!!

          Player Instructions*

 Tracks 1-3 : 00-1F = Blocks
              80-BF = Increase Note
              C0-DF = Decrease Sound(?)
              E0-FD = Increase Sound(?)
                 FE = Stop Music
                 FF = Restart Track

 Sounds     : 00-0C = Save Snd memory
              0C-0F = Snd memory(??)
                a  b  c  d  e  f  g  h
a=Wave on       xx xx xx xx xx xx xx xx
b=Wave off
c=Effect values
d=ADSR(Attack,Decay,Sustain,Release)
e=Pulse value
f=Effect values
g=Effect settings(#$81=beat,#$40appreq)
h=Filterjobs, toneeffects(#$22,#$20??)

Just try, copy values ,Real COOL player!

          Player Instructions*

 Blockedit 00-1F:  DUR.00 -Duration 00
                   SND.00 -Sound 00
                 GLD:00,x -Effect proc.
                           note 00,x
                   END    -End of block

 -=>Always set first duration ,if ya
    wanna change sound+duration

   e.g. WRONG:SND.01  GOOD:DUR.03
              DUR.03       SND.01

 First line of each block ,must be a
 duration setting. Blocks which have
 no notes in it, just END mark won't
 be accepted by player. Don't use
 in track edit.

 Editor is crash-protected. If player
 crashes music stops, restart with F1
