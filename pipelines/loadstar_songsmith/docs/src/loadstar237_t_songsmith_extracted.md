## Key facts extracted from the article:

### Background / Distribution
- SongSmith "never appeared on a regular issue of LOADSTAR"
- It was "a stand-alone music package Softdisk sold on the side -- with the docs
  in a booklet"
- Loadstar 237 is the first time SongSmith appeared as an in-issue feature
  (Dave Moorman brought it to the magazine format)

### Loading and Demo
- Program loads with a bluegrass demo piece on startup

### Main Menu Controls
- **<K>** — Set Key Signature
- **<T>** — Set Time Signature
- **<S>** — Set Speed/Tempo
- **<N>** — New (start composing)

### Voice Selection
- Press **1**, **2**, or **3** to select SID voices 1, 2, 3

### Note Duration Entry
- **W** — Whole note
- **H** — Half note
- **Q** — Quarter note
- **E** — Eighth note
- **S** — (shortest duration; likely 16th or 32nd)
- **D** — Dot modifier (dotted note)
- **R** — Rest

### Screen Navigation
- Backslash (\\) navigates between screens

### Measure Management
- Program tracks "beats per voice" and prevents overfilling measures

### Tied Notes (Workaround)
- No native tied-note command
- Workaround: set a long Release rate (14–15) and place a rest at the
  start of the next measure
- This simulates the sustained sound of a tied note crossing a bar line

### Usage Philosophy
- "the best way to learn it is to play with it. Try everything!"
- Interface is keyboard-driven; article emphasizes it becomes easy with practice
