// Patterns (sequences)
//    <1010 xxxx   -> Preset xxxx
//    >101x xxxx   -> HOLD Duration xxxxx (legato)
//  AA<=0101 0000  -> NOTE
//    BB yyyx xxxx -> Duration xxxxx
//       010x xxxx -> Hold xxxxx
//       001x      -> Slide
//         CC      -> slide low freq
//         DD      -> slide high freq
//       100 xxxx -> Filter
//         CC      -> Cut off/speed
//         DD      -> Duration effect
//  AA>=011x xxxx  -> REST: Duration xxxxx with release
//  $FF    End of pattern
// Track format:
//   Sequence
//   Transpose | Repeat
//   FD xx: loop at xx position
//   FF: loop
// Arpeggio:
//   Wavewform
//   Note (relative 00..7F/absolute 80..FF)
//   Filter freq to apply
//Preset (instrument) format:
// Waveform
// Pulserate
// Pulse level+speed/pulse add byte
// Vibrato delay+speed
// Vibrato level
// FX+Arpeggio:
//    0x arpeggio index
//    10 frequency vibrato
//    20 pulse vibrato
//    40 pulse slide
