## CSDb #10735 — Soundmaster V1.0 (Fire-Eagle, Feb 1989)

**Release type:** C64 Tool  
**Credits:** Code: Jeroen Soede (Fire-Eagle), Michiel Soede (Fire-Eagle). Music: Jeroen Soede, Michiel Soede.  
**SID demos included:** Airwolf (Michiel Soede), Last Ninja Mix (Michiel Soede).  
**Download:** T64 (387 downloads), D64 (63 downloads). External mirror: Pokefinder.org.  
**Related release:** "Fire Eagle Intro 02" used as intro for this release.

**User comment — Fred (24 Mar 2013):**
> "I've replaced the download with the Fire Eagle only release since this release is the non-import version."

The "non-import" phrasing distinguishes this from the Rage for Order / EGO spread version (#180209).

## CSDb #117095 — SoedeSound Editor V1.0 (Soedesoft, 1988)

**User comment — Fred (24 Mar 2013):**
> "This release uses the exact same player/editor as Soundmaster V1.0 but is released under a different name."

Key finding: **"SoedeSound Editor V1.0" and "Soundmaster V1.0" are the same software under two release names.** The 1988 date on this entry is the in-editor copyright year; the tool reached the scene in early 1989. The sidid.nfo annotation confirms: "The editor is also known as Soundmaster or SoedeSound Editor."

## CSDb #117086 — Soundmaster V3.2 (Soedesoft, 1988 on screen)

**User comment — Fred (23 Mar 2013):**
> "This is the 'only for members from Fire-Eagle' release of Soundmaster. Although this version has 1988 on screen, Soundmaster V3.1 is released in 1989 by Magic Disk 64."

Key finding: **V3.2 predates V3.1 as the internal development version** ("only for Fire-Eagle members"). The public release was V3.1 (via Magic Disk 64, 1989). V3.2's 1988 on-screen date is the internal build date. So the public version numbering is inverted vs. development order: V3.2 (internal, 1988) → V3.1 (public, 1989).

## CSDb #180209 — Soundmaster V1.0 (EGO, Fire-Eagle, Rage for Order, 5 Mar 1989)

**Release date:** 5 March 1989 (most precisely dated entry).  
**Credits:** Code: Jeroen Soede (Fire-Eagle), Michiel Soede (Fire-Eagle). Music: Jeroen Soede, Michiel Soede, Red. Import: Asterix! (Rage for Order), G-Man.  
**SIDs included:** Airwolf, Last Ninja Mix, Magic Funk, The Big Deal.

**User comment — Frozen Fire (30 Jul 2019):**
> "Toronto / Canadian import / spread of Soundmaster V1.0"

This is the North American distribution. The extra musicians (Red) and importers (Asterix!, G-Man) indicate the tool was packaged differently for the import scene.

## SoedeSound Editor V1.1 (1992) — CSDb scener profile mention only

The CSDb profile of Michiel Soede (scener #6063) lists a **SoedeSound Editor V1.1 (1992)** as a Tool release with Music credit. No dedicated CSDb release page was found for this entry during this research session. It is likely a later minor revision distributed within the scene. The 1992 date is significantly after the main 1988–1989 development period.
