## Key Observations

1. V1 series: 8 releases between Oct 2002 and Jan 2004 (rapid iteration)
2. V2 series: Initial release Aug 2006, four quick patches in 4 days,
   then NO releases until V2.04 in June 2013 (7-year gap)
3. The "Gamemusic Version" split in V1 (V1.01 had a separate release for
   the gamemusic-mode variant) was eventually merged into a single package
   in later versions
4. Only one known composition explicitly labeled as NinjaTracker format in CSDb
5. The GT1→NT converter predates GT2→NT2 converter by ~10 years
