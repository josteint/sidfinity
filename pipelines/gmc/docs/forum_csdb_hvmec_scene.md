# GMC / Game Music Creator — CSDb, HVMEC, Scene Forums, and comp.sys.cbm Survey

## 1. CSDb Release Pages

### GMC V1.0 (CSDb #7268) — Graffity, Dec 8, 1990

Full title: **"Superiors Game Music Creator System V1"** (alias also used:
"GMC V1.0").

Credits (from CSDb release page):
- **Code:** Brian and Jay (Graffity)
- **Music:** Andy and Brian (Graffity)
- **Graphics:** Jay (Graffity)

The release bundles 29 SID music files by Brian and Andy, including "Action
March," "Boogie," "Clock Rock," "Magic Flute," "Rock'n'Roll."

Download count: 1,030 (gmcv1.t64) + 235 (gmcv1.zip) + 173 (D64 with intro and
demotunes).

Community comments (from CSDb, verbatim approximations):
- One user: "really solid to work with and it is really good at producing some
  really twisted filtering."
- Another: "They should have called this tool DMC V1.0" — referencing the
  perceived equivalence between GMC and the later DMC tool.
- A contributor uploaded "a proper version (including a great intro from Graffity
  and all the original demotunes)" — implying an earlier download had integrity
  issues.

**Technical content from CSDb page:** NONE (metadata + download links only).

### GMC V2 (Unfinished) (CSDb #44814) — Fenek (Arise / Protovision), Dec 20, 2006

Alternative title: "tydzienbezsensownejroboty" (Polish: "week of senseless work").
Download count: 1,192.

From CSDb release notes (verbatim approximation):
> "GMC is a music editor by Graffity, a grandfather to DMC."
> Fenek "disassembled the player and recreated the editor and the player
> removing those restrictions, and optimizing the player's code."

**Key facts:**
- Fenek reverse-engineered ("disassembled") the GMC V1 player to build a new
  editor.  This confirms the GMC player binary is decompilable.
- Fenek claimed to have "removed instrument count limitations" and "optimized the
  player code."  This implies the original GMC V1 had a specific instrument count
  ceiling (possibly 16, given the 4-bit index from the nibble decode).
- The new editor "resembled DMC," which Fenek also acknowledged as the successor.
- Project abandoned after one week; Fenek produced limited music with it.

**Technical significance:** Fenek's RE of the player is the most direct third-
party source confirming the GMC binary is accessible and the player architecture
is decompilable from the HVSC SID files.  If Fenek's reconstructed editor is
ever located (the CSDb page offers a download), its source would be the closest
thing to a GMC disassembly available.

### Graffity Group (CSDb Group #193)

Founded: October 1990.  Dissolved: October 1994 (revived 1996).

Key members in the GMC/DMC era:
- **Brian** (music, coder, founder) — author of all GMC and DMC versions
- **Jay** (musician, ex-member) — co-creator of GMC V1.0 (code co-credit)
- Matrix, Maxwell (ex-members)
- Cheesion (coder, 1992–2023)
- Cybortech (graphician, 1992–)

Tools released by Graffity in the GMC/DMC era (in order):
1. Digieditor V1.3 (1990) — sample/digi editor
2. GMC V1.0 (Dec 1990)
3. GMC V1.6 (Dec 1990)
4. DMC V1.2 (Feb 4, 1991)
5. DMC V2.0, V3.0, V4.0 (all 1991)
6. DMC Relocator (1991)
7. DMC V4.05 (1992)
8. DMC V5.0 (1993)
9. DMC V5.1 Package (1994), V5.1+ Package (1994)

scene.hu description (paraphrase from page tagged 'c64'):
"Graffity was one of the most iconic Hungarian C64 groups of the early 1990s.
They were known for the unreleased but legendary Justinblue demo, the DMC
(Demo Music Creator) — which was one of the most successful C64 music editors

## 2. HVMEC (High Voltage Music Engine Collection)

URL: https://hvmec.altervista.org/blog/?cat=8

Three GMC entries archived at HVMEC:

| Version | HVMEC URL | Copyright | Type |
|---------|-----------|-----------|------|
| GMC V1.0 | ?p=1256 | 1990 Graffity Brian | Editor |
| GMC V1.6 | ?p=1265 | 1990 Graffity Brian | Editor |
| GMC V2.0 | ?p=1272 | 199? Graffity Brian | Editor |

Downloads at HVMEC: each page has `Editor v1.x.d64` and `GMC_SONGS.D64`
as compressed download links.  The editor binaries are the primary source for
carving the GMC player (same technique as DMC in
`dmc4editor_embedded_player_notes.md`).

**HVMEC V1.0 keyboard map** (from ?p=1256):

Track editor:
- F1: Start music; F3: Stop; F5: Continue; F7: Fast playback
- SHIFT+X: Exchange tracks; SHIFT+C: Copy; SHIFT+D: Duplicate
- SHIFT+T: Set tune (0–7)
- INST: Insert step; DEL: Delete step; CLR: Clear all tracks
- `S`: Put sector reference
- `+`/`-`: Transpose
- SHIFT+E: Insert END marker; C=+E: Insert STOP command
- SHIFT+RETURN: Open Sector editor

Sector editor:
- C=+D: Put DUR (duration)
- C=+S: Put SND (sound/instrument)
- C=+A: Put APM (amplitude/modulation)
- C=+G: Put GLD (glide)
- C=+H: Put HLD (hold)
- `\`: Insert END marker
- Brackets `[]`: Choose sectors
- `<`/`>`: Transpose notes (pitch adjust)
- DEL: Remove note; INST: Insert note; CLR: Clear sector

**HVMEC V2.0 keyboard map** (from ?p=1272):

Track editor (V2.0 changes from V1.0):
- SHIFT+A: Navigate to Arpeggio section (new in V2.0)
- SHIFT+D: Access Drum section (new in V2.0)
- SHIFT+S: Insert STOP marker (moved from C=+E)
- SHIFT+RETURN: Open Sector editor (same as V1.0)
- SHIFT+E: Insert END marker (same)
- SHIFT+P: Access Options (new in V2.0)
- SHIFT+X/C/D: Exchange/Copy/Duplicate tracks (same but SHIFT prefix)

Sector editor (V2.0 changes from V1.0):
- CTRL+D: Put DUR (key changed from C=+D)
- CTRL+S: Put SND (key changed from C=+S)
- CTRL+A: Put APM (key changed from C=+A)
- CTRL+G: Put GLD (key changed from C=+G)
- CTRL+H: Put HLD (key changed from C=+H)
- `\`: Insert END (same)
- `<`/`>`: Adjust pattern values (same meaning)
- DEL/INST/CLR/brackets: same as V1.0

**New in V2.0 (from keyboard map evidence):**
- Arpeggio section (SHIFT+A from track editor) — suggests explicit arpeggio
  programming, possibly the wave-table equivalent or a separate arpeggio table.
- Drum section (SHIFT+D) — suggests dedicated drum/percussion mode, consistent
  with the "abs freq hi" drum mechanism in DMC.
- Options screen (SHIFT+P) — possibly speed, tuning, or configuration.

**HVMEC V1.6 note (from ?p=1265):**
"Aka: Superiors Game Music Creator System" — confirms the "Superiors" branding
on the tool (both the release name and the sidid classification "GMC/Superiors").
No additional technical details beyond the V1.0 map.  V1.6 appears to be a
minor update (bug fixes only, given the two versions within the same month Dec 1990).

BD ?? ?? 9D ?? ?? BC ?? ?? 18 0A 0A 0A 0A 85 ?? AD ?? ?? 69 00 85 ??
A0 00 B1 [END]
```

### GMC_V2.0/Superiors:
```
E1 EE FD BD ?? ?? 9D ?? ?? A8 B9 ?? ?? 9D ?? ?? B9 ?? ?? 9D ?? ??
BD ?? ?? 9D ?? ?? A8 29 F0 85 FC 98 29 0F 18 6D ?? ?? 85 FD A0 00

Note the shared 30-byte prefix between V1 and V2.0.  Both sidid.cfg copies
(GitHub cadaver/sidid main copy + the WilfredC64 player-id copy) are byte-
identical for these entries.

## 9. V1.0 → V2.0 Differences (Synthesised)

| Feature | GMC V1.0 | GMC V2.0 |
|---------|----------|----------|
| Instrument decode | ×16 multiplication (4× ASL A) | Nibble split (hi/lo) — packed-byte fields |
| Command prefix keys | C= + letter | CTRL + letter |
| Arpeggio section | Not separately documented | Explicit section (SHIFT+A) |
| Drum section | Not separately documented | Explicit section (SHIFT+D) |
| Options | Not present | Options screen (SHIFT+P) |
| Max instruments | Unknown; likely 16 (4-bit multiply) | OPEN; nibble encode → possibly 16 lo-field |
| Sector command set | DUR, SND, APM, GLD, HLD, CONT, END | Same names confirmed; encoding different |
| Player code | Related to V2.0 but distinct (sidid diverges after shared prefix) | See `sidid_signature_analysis.md` |
| HVSC population | ~437 SIDs (majority) | 9 SIDs (all 2010–2023, modern revival by NecroPolo) |

The V2.0 "modern revival" status (9 SIDs, all 2010–2023) means V2.0 is a niche
variant: either NecroPolo obtained an unreleased V2.0 editor or wrote his own
using Fenek's disassembly as a base.  No public V2.0 editor binary was found
on CSDb; only HVMEC hosts it.

## 10. Laxity's GMC Use

The CSDb release GMC V1.6 100% (id=156855) includes "Star Dream" by Laxity
(Maniacs of Noise / Vibrants) — a significant mainstream composer using GMC.
This is archived in HVSC.  Laxity's GMC tunes may be useful canaries because:
- Laxity was a technically demanding composer (good coverage of GMC's filter
  and effect capabilities).
- The "100% fixed" re-release implies the original had bugs that Case (TAT) found
  and patched — possible that the fix touched the player code, making this binary
  slightly different from stock GMC V1.6.

## Leads to Follow

1. **Download HVMEC GMC binaries** (`hvmec.altervista.org/blog/?p=1256`,
   `?p=1265`, `?p=1272`) and carve the player (same method as
   `dmc4editor_embedded_player_notes.md`).  This is the single highest-value

2. **Locate Fenek's GMC V2 (Unfinished) editor** (CSDb #44814, download link
   exists with 1,192 downloads).  If Fenek's reconstructed editor contains
   the original player or annotated 6502 source, it could short-circuit the
   disassembly phase.

3. **Lemon64 search (when back online):** search for "Game Music Creator" and
   "GMC" threads.  The DMC research wave found a useful Lemon64 DMC thread;
   a GMC thread may exist.

4. **scene.hu Hungarian-language interview** — the scene.hu DMC article
   mentioned Graffity but not GMC by name.  A Hungarian-language search
   ("Játékzenekészítő" = "Game Music Creator"?) or a direct interview with
   Brian (active on Demozoo through 2025 as Balázs Farkas) could provide
   first-person format details.

   revival — he wrote all 9 modern V2.0 SIDs.  He may have documentation or
   a tool he used.

   and one other Laxity GMC tune to get the write-log profile.  This gives
   empirical evidence of what GMC actually emits, before any disassembly.
