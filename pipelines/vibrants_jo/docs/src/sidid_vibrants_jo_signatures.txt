# Notes on Vibrants/JO signatures:
# - Sig 1: C9 80 D0 ?? BC ?? ?? C8 B1
#   CMP #$80 / BNE ?? / LDY abs,x / INY / LDA (zp),y
#   Note-value check pattern: $80 = note boundary sentinel
#
# - Sig 3: BC ?? ?? B1 ?? C9 F0 ...
#   LDY abs,x / LDA (zp),y / CMP #$F0 / BNE ... / INY / LDA (zp),y
#   Pattern: load from indirect table, compare against command byte $F0
#
# - Sig 4: BC ?? ?? B1 ?? C9 FF ...
#   Similar but checks $FF (end-of-sequence / restart marker)
#
# - Sig 5: BC ?? ?? B1 ?? C9 60 90 ?? 38 E9 60 ...
#   Checks $60 (note value 96? or command $60), then SEC/SBC #$60 (subtract $60)
#   Suggests notes stored as values where >=60h = special command
#
# - Sig 8: C9 D0 90 ?? E9 D0 0A 0A 0A 9D
#   CMP #$D0 / BCC / SBC #$D0 / ASL / ASL / ASL / STA abs,x
#   Suggests instrument index packed: value >= $D0 -> subtract $D0, shift left 3 = instrument select
#
# - Sig 9: A2 02 BC ?? ?? A9 00 99 05 D4 99 06 D4 A9 08 99 04 D4 CA 10 ?? 60
#   LDX #2 / LDY abs,x / LDA #0 / STA $D405,y / STA $D406,y / LDA #8 / STA $D404,y / DEX / BPL / RTS
#   This is the gate-off routine: loops X=2,1,0 (3 voices), writes AD=0, SR=0, Ctrl=8 (test bit, gate off)
#   This is the INIT/reset part that silences all voices.
#
# - Sig 10: 30 03 4C ?? ?? A9 00 9D ?? ?? A9 08 99 04 D4 98 48 A0 00 BD
#   BMI +3 / JMP / LDA #0 / STA abs,x / LDA #8 / STA $D404,y / TYA / PHA / LDY #0 / LDA abs,x
#   Confirmed present in Airwolf_Theme.sid at file offset $6FB.
