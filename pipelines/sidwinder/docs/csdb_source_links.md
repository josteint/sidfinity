## Source Archive Contents (SIDwinder_V0123_src.zip, 341KB)

### Documentation files:
- `COPYING` — GPL license text
- `README` — project readme
- `SUMMARY` — feature/format summary
- `GENERAL` — general documentation
- `HISTORY` — version history / changelog
- `PROGRAM` — program documentation
- `PLUS4` — Plus/4 specific notes
- `SIDW0122` — notes about V01.22 differences

### Main source files (assembly language, likely xa65 or similar):
- `ED.ASM` — Editor source
- `PACKER.ASM` — Packer source
- `PLAYER.ASM` — Player (runtime) source
- `SIDR.ASM` — SID reader/utility
- `VIEWER.ASM` — ASCII file viewer source
- `PLAY0122.ASM` — V01.22 playback routine

### Binary data files:
- `CHARS.BIN` — Character set graphics
- `MASKS.BIN` — Mask data
- `VCHARS.BIN` — Variant character data
- `SECTORS.BIN` — Sector data
- `TRACKS.BIN` — Track data
- `PLAY0122.SEQ` — V01.22 sequence data

### Subdirectory structure:
- `PRE_0123/` — contains subdirs: 0122, 0120, REANIM (prior version snapshots)
- `SRC/` — main source folder
- `TOOLS/` — build tools

### License
"First release under GPL" — the V01.23 release was the first GPL-licensed version of SIDwinder.
