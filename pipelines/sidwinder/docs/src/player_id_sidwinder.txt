## WilfredC64/player-id — SidWinder Coverage

The player-id repository (Rust implementation by Wilfred Bos) ships the following
config files in its config/ directory:

  config/sidid.cfg   (76,823 bytes — primary signature database)
  config/sidid.nfo   (44,603 bytes — player notes / attribution)

## Detection Algorithm

player-id uses the BNDM (Backward Nondeterministic DAWG Matching) algorithm to
scan SID binaries for signatures. Unlike cadaver/sidid (which is a standalone C
binary), player-id is a Rust library + CLI tool designed for cross-platform use.

Signature contributors listed in the repo: Wilfred Bos, iAN CooG, Professor Chaos,
Cadaver, Ninja, Ice00, Yodelking.

## Conclusion

No additional SidWinder-specific content beyond the shared sidid.cfg was found in
the WilfredC64/player-id repository. No Rust-level special-casing for SidWinder.
The single signature entry is the only detection method used.
