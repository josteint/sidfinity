 FEATURES - HARDWARE C64
        VacSiD is able to emulate the C64-soundchip, processor and
        related hardware for playing 64-tunes on standard PC with
        a Soundblaster(tm), Gravis Ultrasound(tm) or AMD Interwave(tm)
        soundcard (PAS16 removed at the moment).
        SiD (MOS6581)
                - 3 FM-Voices, _completly_ emulated
                - Real white noise, no samples
                - 1 Digi-Channel, controlled through PlaySid-Registers
                  _and_ unpatched NMI-Songs using CIA#2/Volume Registers
                - Analoge filter emulation (not 100%)
                - 2nd SiD switchable at D420 (aka "stereo-sid")
        CPU (MOS6510)
                - Full bankswitching emulated (64k RAM/20k ROM)
                - All legal OP-Codes
                - Partitially illegal OP-Codes
                - Partitially decimal arithmetics
                - NMI and IRQ available
        CIA (MOS6526)
                - CIA#1 and CIA#2 interrupt counters
                - Interrupt lines connected to 6510-IRQ and 6510-NMI
        VIC (MOS6567)
                - D012/D011 available for "random" numbers
                - Scanline-IRQ available
        MEMORY
                - 64k Host RAM Memory
                - ROMs: BASIC, KERNAL, CHAR
                - 2 single, independent RAM Banks at DE00 and DF00
                - 1k*4 color-RAM at D800
 FEATURES - HARDWARE PC
        Following Soundcards are supported:
                - SoundBlaster (tm)             : Mono  , up to 22kHz
                - SoundBlaster Pro (tm)         : Mono  , up to 44kHz
                - SoundBlaster 16 (tm)          : Stereo, up to 44kHz
		- Gravis UltraSound		: Stereo, up to 44kHz
		- AMD Interwave (GUS IW)	: Stereo, up to 64kHz
		- Pro Audio Spectrum 16		: Stereo, up to 44kHz (*)
                ( * = deleted, will be implemented in later versions again)
        MINIMUM Requirements:
                - 486/33 CPU (gives you mono-output at 22kHz)
                - SB
        BETTER:
                - a VESA VLB/PCI VGA Card
                - 486 2/66 CPU or better
                - AMD Interwave (width 64kHz)
        (44khz Stereo SB-Output on a Pentium75 uses approx. 40% CPU-
         Ressources. So check out!)
 FEATURES - SOFTWARE
        VacSiD features:
                - "Pseudo"- Stereo-Output
                - Compressor/Limiter
                - Playlists  
                - Online-Help
                - Comfortable File-Selector based on CubicPlayer
                - SongMessage detection
                - Highly configurable player
 FILESELECTOR / MENU
        Use it like Cubic, btw. check out F1 for Keys-description.
        Reading RAR & ZIP & ARJ-Archives implemeted, also sub-directorys.
 COMPATIBILITY
        VacSiD recognizes following files as "SiD-Files":
                - DAT with SID (SidPlay PC)
                - DAT with INF (PlaySid AMIGA)
                - DAT only (with PlaySid-Header)
                - DAT only (without song-information) up to 90%
        "Galway-Noises", which are special samples, are not
        completely supported. (I don't have any informations about)
