# Research documents (deprecated location)

50+ research documents on three SID engines, accumulated during their
reverse engineering. Moved from `src/<engine>/docs/` during the USF v2
src/ cleanup so that `src/` could focus on the active code.

```
Companion/docs/     21 docs on the 1984 Bowden Companion engine
                    (used by Up_up_and_Away.sid)
Rob Hubbard/docs/   7 docs on Rob Hubbard's engines (older subset)
hubbard/docs/       52 docs on Hubbard's engines:
                    interviews, disassemblies, technical analyses,
                    driver version history, ecosystem references
```

These are reference material — interviews, scanned magazine articles,
GitHub disassemblies, codebase64 articles, forum threads — not code.
Engine research is timeless even when our pipeline architecture
changes.

## Browsing

These docs are how you'd onboard before working on a new engine in
the same family. Companion docs informed
`pipelines/companion/`; Hubbard docs informed every engine in
`pipelines/hubbard/`. They're useful starting points for any new
member of those families.
