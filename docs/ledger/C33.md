### C33 — closing a `Params.fields` escape-hatch key → a typed field (byte-identity carrier refactor)

**Problem class.** A value already carried in the USF via an untyped
generic-`Params.fields` string key — the §7/§8-adjacent escape hatch. It is
NOT an opaque-bytes leak (C7) and NOT a hand-patched-player wedge knob (C19):
it's a clean, behavior-named scalar sitting in the wrong container
(init-phase engine state, a mechanism scalar). The uready "no escape hatches"
criterion — and the Move-1 escape-hatch pass — wants it typed.

**PRESENTS:** a leak/escape-hatch scan flags a `params.fields['<key>']` that
affects the write stream but isn't quite musical *content* per se. The
instinct is either "add a schema field" (→ trips the schema-addition alarm)
or "type it for the one engine that uses it" (→ under-scopes).

**Canonical solution (2026-07-21, `speed_ctr_init`/`fade_frac_init`).** Treat
it as a **byte-identity CARRIER REFACTOR, not a schema addition** — the value
already lives in the USF, so there is no representation gap and the "schema
additions are suspicious by default" discipline does not apply; the gate is
byte-identity, not re-verification. Recipe:

1. **Census ALL consumers first** — grep every reader AND writer across
   engines. A key named for one engine's need is often cross-engine SHARED
   (the scope surprise: a "v5-only" flag was actually Hubbard '85 + 5TT + v5,
   ~5× the estimate). The census also turns up DEAD readers — a model field
   *set from params but never read* — to delete for free.
2. **Home it by cloning an EXISTING typed field of the same trichotomy
   category** — its grammar rule, parser collect, writer emit, and dataclass
   field, verbatim. (§4.5 engine-state priming → an `InitState` scalar beside
   `slide_phase`; the shared `init_block` grammar rule then serves BOTH the
   file-level and per-subtune init in one addition.)
3. **Type by MUSICAL / SEMANTIC category, NEVER by a composer-internal
   grouping.** A composer set that bundles keys for its own dispatch
   (`_PER_SUBTUNE_MECHANISM`, a per-emitter `_Inputs` cluster) mixes
   semantically-different keys; typing by that grouping re-leaks composer
   structure into the schema — a §8 analog. Migrate only the keys of the one
   category; leave the semantic siblings in params (they are a separate
   question, often a different class entirely — C19 wedge / behavior config).
4. **Gate = regenerate the USF (its TEXT changes by design) + rebuild,
   require the `.sid` MD5-identical** to a pre-change baseline, across EVERY
   consumer family — not just the one the flag named. Byte-identity ⇒
   identical write stream ⇒ identical verdict, ~100× cheaper than
   re-verifying. Values that are 0 (the dataclass default) simply emit
   nothing; a subtune that inherits resolves the same as before iff every
   non-zero value in the corpus is explicitly stated (the writer emits
   non-zero only) — the gate confirms this holds.

**Trap — a FULL-in-regression member can hide a BROKEN extract path.**
Regression builds each member from a STORED `.usf`, not from regeneration, so
a member's regeneration/extract path can be silently broken (a positional
`_Inputs`/dataclass construction that drifted N fields behind the growing
dataclass) while its verdict stays FULL. Regenerating to run the byte-gate is
what SURFACES it — another reason the gate must regenerate, never reuse stored
artifacts. The C20 relative at the extract layer: a passing verdict never
proves the extract still *runs*.

**Boundary — when this is NOT the class.** Opaque/verbatim musical bytes or a
content-by-reference blob = **C7** (deconstruct/exclude, don't just re-home).
A wedge knob whose canonical home genuinely IS params (a C19 hand-patch
parameter) — leave it; typing is for recoverable structure, not wedge state.
A params key that DESCRIBES orig memory geometry is a §7 *violation* to
DELETE and replace with a behavioral flag, not to type
(`offtable_redirect`/`sectpos_shadow`, C7-(b)) — a heavier remediation than
this clean re-home.

**Status:** methodology (recurring ≥3×: `cia_period`→`Environment` §4.3,
`slide_phase`→`InitState` §4.5, `speed_ctr_init`/`fade_frac_init`→`InitState`
§4.5).
**Consumers:** `src/usf/types.py` (`InitState`/`Environment`), the shared
`grammar.lark` + `parser.py` + `writer.py` clone, and the per-engine
extract/composer read+write sites. Occurrence detail: commit `718ade06` +
