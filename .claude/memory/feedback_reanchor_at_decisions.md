In long sessions I drift from the principles — not because they aren't
loaded, but because I invoke them to **justify** the locally-convenient
choice instead of running them as an **adversarial check that could
overturn it**. The user has had to be my conscience. Stop making them.

**The discipline — at EVERY representation or correctness decision, STOP
and re-run these as challenges (try to BREAK the current choice, not
defend it):**

1. **CORE TENET (write-log is the only target).** Am I reaching for
   byte-identity, or reproducing the engine's code/structure/table
   layout? Those are NEVER required. Restate the problem in terms of the
   `$D400-$D418` write-log stream and restructure freely. (This session I
   kept saying "re-packs byte-identically" as if it mattered — it
   doesn't. See [[feedback_ground_truth]].)

2. **USF principle (`docs/usf_representation_principle.md`).** Am I
   carrying RAW BYTES (Pole B) or an OPAQUE INDEX (Pole A) — or, worst,
   both (a raw-byte program selected by an arbitrary index)? Then ask the
   question the principle IS: *could this be parametric over a musical
   basis?* What would a model trained on this actually LEARN? Actively
   hunt for a more parametric/musical form — do not wait for the user to
   ask "is this good for ML?" That question is the principle; ask it
   unprompted. The §10 provenance line: "When in doubt, re-run that
   challenge." (This session: I chose a flat shared pulse/filter byte
   table + index and rationalized it via the freq_overrun precedent; the
   user pushed, and the right answer was per-instrument PWM/cutoff
   ENVELOPES — parametric, cross-engine. See
   [[feedback_usf_representation_principle]].)

3. **uready (the 6-criteria gate, [[feedback_uready_vocabulary]]).** Does
   this choice advance or regress: orig-free §9, no escape hatches,
   factored/reversible USF, representative verification, feature-dimension
   accounting, documented residue? State the impact, don't skip it.

**The tell that I'm drifting:** I'm citing a precedent or a slogan to
*defend* a choice that was easy/safe (byte-identical, raw-correct,
content-by-reference) rather than describing the adversarial test I ran
to *try to beat it*. When I notice that tell, I have already failed the
check — re-run it for real.
